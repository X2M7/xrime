# 文档提供器的遍历和复制限制

文档提供器的一次目录遍历最多检查 10,000 个节点、32 层目录；一次复制最多处理 512 MiB。超限会在开始复制或删除前失败。删除和搜索不按文件字节数限制。这个复制上限可能使以前能够复制的大目录或大文件需要拆分处理。

复制前会记录文件长度，并尽力检查目标可用空间。复制过程中，如果文件变长或变短，操作会失败。空间检查无法预知其他进程的写入；操作开始后的普通 IO 故障或并发修改可能留下部分复制结果，删除也无法保证整体原子性。

Android 26 及以上逐项枚举目录。Android 21–25 的系统目录枚举可能先为整个目录分配数组，再由应用检查数量，因此节点预算不构成这些版本的严格内存上限。文件路径的常规检查也无法完全消除其他进程并发替换路径组成部分的竞态。
