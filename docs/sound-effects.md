# 按键音效

启用自定义音效后，文件须位于用户数据的 `soundeffect` 目录下或其子目录中；文件路径不能使用绝对路径、上级目录或符号链接。每个音频文件最多为 16 MiB。旧音效包如果引用了目录外的文件、符号链接或超大音频，需要把文件复制到音效目录内，或重新编码成较小文件。

音效包可以包含超过 64 个样本；应用最多同时缓存其中 64 个已加载样本。刚切换音效、首次使用某个样本或样本从缓存淘汰后，加载期间会尝试使用系统按键音。系统音量和系统声音设置仍会影响实际播放。

系统按键音、自定义音效和自定义加载期间的系统回退均使用有界后台队列。连续按键极快或设备音频服务长时间阻塞时，过期或超出队列容量的按键音可能不会播放。关闭按键音会撤销尚未领取的播放请求；关闭时已经开始处理的播放请求可能仍会播放一次。

音效文件的安全打开以已打开的目录为边界；如果其他进程并发移动已打开的目录、修改文件内容或使用硬链接，不能保证文件当前路径始终位于原目录内。
