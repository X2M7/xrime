# 剪贴板规则

在设置的剪贴板页面可分别填写比较规则和过滤规则，每行一条 Java 正则表达式；空白设置不会过滤普通文字。规则更改后会用于随后的复制事件，不需要重新启动。

过滤规则使用**整段匹配**：`secret.*` 会过滤 `secret123`，但不会过滤 `my secret123`。要匹配任何包含 `secret` 的单行文本，可用 `.*secret.*`；`.` 默认不匹配换行。过滤命中的内容不会加入历史记录，也不会显示为新建议。

比较规则会按行依次移除匹配部分，移除后为空时不记录该条内容。例如 `[0-9]` 会让纯数字内容被忽略，而 `abc123` 仍可记录。当前历史记录的重复判断使用原文完全相等，并不会把移除规则后的不同原文合并；不要依赖比较规则隐藏保留下来的敏感片段。

正则写错时，剪贴板历史会暂停记录新内容直到规则修正，以免误存本来要过滤的内容。此设置不会清除已有历史，也不会影响系统剪贴板本身。隐私模式与 Android 标记为敏感的剪贴板内容仍按各自的保护规则处理。
